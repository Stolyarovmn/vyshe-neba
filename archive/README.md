# Архив

Документы и отчёты, которые больше не описывают текущую игру или процесс. Они сохранены для истории, в них нельзя искать действующие правила, и на них не должны ссылаться новые документы.

| Папка / файл | Что это | Почему в архиве |
| --- | --- | --- |
| `legacy-rocket-outputs/` | разборы, критика и документы старой игры `outputs/rocket` (Into Space, физика, звук, трафик по высотам) | старой игры нет ни в одной текущей ветке; справочники по трафику скопированы в `main:game/docs/reference/`, их читают тесты симуляции |
| `study-critiques/` | независимые ревью спрайтов, сцен, самолётов, базы, спутника и рельефа старой игры (октябрь 2026) | относятся к спрайтам и сценам, которые в текущем рантайме заменены |
| `ART_PROGRESS_world_sprites_2026-10.md` | журнал производства world-спрайтов через ref2game (самолёты, шары, небо, площадки) | путь `live/`, `outputs/rocket/dist`, `work/` исчезли; журнал закрыт |
| `MISSING_ASSETS_PROMPTS_2026-10.md` | список недостающих построек и ручные промпты | все 14 построек E0 нарисованы; способ генерации заменён на `art/docs/ART_DIRECTION_HD_PIXEL.md` |

Удалённые из репозитория workflow (ноябрь 2026): `b01-atlas-repair`, `b01-motion-qa`, `b01-rig-qa`, `b01-runtime-qa`, `rocket-modular-candidate`, `rocket-modular-candidate-branch`, `rocket-modular-promote` — все запускали скрипты из `outputs/rocket/`, которых нет, и срабатывали только на пушах в `main`, где нет папки `art/`. Их текст доступен в истории Git.

# Чистая типографика и пиктограммы

Подготовлен идемпотентный скрипт `work/ui-polish.cjs`: меняет Courier на Segoe UI с Arial как запасным шрифтом, уменьшает начертание с жирного до 600, удаляет двойной рисунок букв, согласует линии рисованных пиктограмм на толщине 1,8 с округлёнными концами и соединениями. Правки ограничены отрисовкой и измерением текста/иконок; физика, ввод, цены и сохранение не меняются. CSS экранных SVG-кнопок приведён к той же геометрии.

Проверена синтаксическая корректность скрипта. Сам скрипт ещё не применён к `game.js` по договорённости с основным агентом: он должен запускаться после его текущих правок. При применении проверяет ожидаемые точки замены и синтаксис результирующего файла до записи. Повторный запуск безопасно завершается без изменений.

После применения нужны новые снимки основных экранов и автоматическая проверка границ текста: другой шрифт меняет метрики. Проверить встроенный HTML после сборки, отдельные экранные SVG, отсутствие тени букв, сохранение пиксельной резкости игровых растров. Сохранено `image-rendering:pixelated`, поэтому игровые изображения не размываются.

# Инфраструктура космодрома

Этот каталог описывает production-структуру покупаемых объектов базы. Все финальные изображения обязаны следовать `art/style_bible.txt` и принципам `ref2game`: физический объект находится в арте, движение, свет, дым, вода, тросы, реакция на события и прочие динамические эффекты принадлежат коду.

## Эпохи

Для каждого объекта обязательны шесть художественных вариантов:

- 1978 — ручная/гаражная инженерия;
- 1986 — промышленная механизация;
- 1998 — испытательный комплекс и электроника;
- 2015 — современная автоматизация;
- 2035 — роботизированная инфраструктура;
- 2060 — распределённая автономная система.

Эволюция должна менять инженерную идею, а не просто цвет. Функция объекта и основной силуэт при этом остаются узнаваемыми.

## Runtime-путь

Финальный PNG для каждого варианта:

```text
outputs/rocket/dist/assets/infrastructure/<object>/<year>.png
```

Полный перечень из 84 обязательных вариантов находится в `manifest.json`.

Если PNG ещё отсутствует, `infrastructure.js` рисует эпохозависимый procedural fallback. Это позволяет разрабатывать и балансировать механику до завершения арта. Финальный PNG автоматически заменит fallback без изменения кода.

## Отдельные части

Когда часть должна двигаться независимо, не запекать её намертво в фон. Для production-арта допустимы:

```text
<object>/<year>.png              основной корпус
<object>/<year>-parts.png        независимые физические части
<object>/<year>-anchors.json     pivot/attachment points
```

Runtime сейчас использует основной PNG и procedural motion. При появлении `parts` модуль переводится на cut-out rig без изменения игровой механики.

## Anchor

Наземные объекты используют `bottom-center` как общий placement anchor. Отдельные части получают собственные pivot-точки. Anchor не должен плавать между эпохами и состояниями.

## Что не запекать

В финальный PNG не входят, если это не физическая часть материала:

- glow и bloom;
- дым, пар, вода, пыль;
- динамическое пламя;
- трос между движущимися точками;
- radar sweep;
- свет предупреждающих маяков;
- motion blur;
- эффекты запуска и аварии.

## Проверка каждого варианта

1. Читается в фактическом игровом размере.
2. Сохраняет полный силуэт на прозрачном фоне.
3. Работает рядом с ракетой и фоном соответствующей эпохи.
4. Не содержит псевдотекста, случайных деталей и AI-артефактов.
5. Свет и пиксельная структура соответствуют `style_bible.txt`.
6. Отличается от предыдущей эпохи конструктивно, а не только палитрой.
7. Подвижные части можно отделить или явно определить их pivot.

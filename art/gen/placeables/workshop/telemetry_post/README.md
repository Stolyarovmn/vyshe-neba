# W03 — Телеметрический пост (`telemetry_post`)

После полёта показывает траекторию, скорость, расход, повреждения и события; позднее позволяет сравнивать последний полёт с лучшим и включать ghost прошлой траектории.

- runtime canvas: `156×124 LP`
- shared anchor: `(78,120)` bottom-center
- sockets: `wall | floor_back`
- value: Information
- cost target: M

## Эпохи

- `e0_1978.png` — E0 / 1978: бумажный самописец, рулоны бумаги и стрелочные приборы
- `e1_1986.png` — E1 / 1986: осциллографы и массивная консоль
- `e2_1998.png` — E2 / 1998: CRT-мониторы и стойка телеметрии
- `e3_2015.png` — E3 / 2015: цифровая telemetry desk
- `e4_2035.png` — E4 / 2035: проекционная поверхность над компактной консолью
- `e5_2060.png` — E5 / 2060: пространственная интерактивная модель над минималистичной рабочей станцией

## Animation

flight_return: телеметрия постепенно появляется поверх дисплеев; compare: включается второй слой/ghost; idle: почти статичен. E0 recorder/reels могут вращаться только после отдельного part pass.

По `ref2game` дисплейные данные, glow, динамический свет и прочие FX не запекаются в PNG. Если движение требует физической детали, она будет выделена отдельным part-sheet и pivot будет измерен на утверждённом арте.

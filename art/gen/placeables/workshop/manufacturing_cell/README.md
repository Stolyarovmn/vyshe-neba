# W05 — Производственный участок (`manufacturing_cell`)

Производит выбранный существующий расходник за несколько завершённых полётов; стартовая цель — один предмет за 3–4 полёта, без real-time таймера.

- runtime canvas: `176×134 LP`
- shared anchor: `(88,130)` bottom-center
- sockets: `floor_back | wall`
- value: Economy / Capability
- cost target: L

## Эпохи

- `e0_1978.png` — E0 / 1978: верстак и ручной токарный станок
- `e1_1986.png` — E1 / 1986: промышленный токарно-фрезерный станок
- `e2_1998.png` — E2 / 1998: CNC-станок с моторизованной кареткой
- `e3_2015.png` — E3 / 2015: закрытый machining center
- `e4_2035.png` — E4 / 2035: роботизированная производственная ячейка
- `e5_2060.png` — E5 / 2060: автономный фабрикатор с несколькими рабочими головками

## Animation

progress: короткая производственная сессия после завершённого полёта; finish: готовая деталь переходит в выходной лоток. Для WORK обязательны реальные moving parts, а не движение всего PNG.

По `ref2game` дисплейные данные, glow, динамический свет и прочие FX не запекаются в PNG. Если движение требует физической детали, она будет выделена отдельным part-sheet и pivot будет измерен на утверждённом арте.

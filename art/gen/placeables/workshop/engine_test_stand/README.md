# W02 — Испытательный стенд двигателя (`engine_test_stand`)

Канонический anchor-art покупаемого объекта мастерской. Источники правил: `art/style_bible.txt`, `art/placeables/PRODUCTION_MANIFEST.md`, `ref2game`.

## Соответствие эпох

| файл | эпоха | год | визуальная стадия |
|---|---|---:|---|
| `e0_1978.png` | E0 | 1978 | грубая огневая рама, открытые баллоны и стрелочные приборы |
| `e1_1986.png` | E1 | 1986 | промышленный испытательный стенд с гидравлическими зажимами |
| `e2_1998.png` | E2 | 1998 | sensor/CRT стенд с моторизованными узлами |
| `e3_2015.png` | E3 | 2015 | закрытая модульная test-cell |
| `e4_2035.png` | E4 | 2035 | robotic self-positioning stand |
| `e5_2060.png` | E5 | 2060 | adaptive real-time test-cell |

Все runtime PNG имеют canvas `190×126 LP`, общий bottom-center anchor `(95,122)`, общий коэффициент уменьшения для всей линейки и поэтому не прыгают по масштабу при смене эпохи.

## Gameplay role

Перед полётом стенд позволяет провести тест и выбрать **один** временный режим:

- `THRUST` — тяга;
- `ECONOMY` — экономичность;
- `COOLING` — охлаждение.

Первичная цель эффекта из production manifest — порядка `5–8%`: стенд даёт тактический выбор, но не заменяет постоянные upgrades.

## Анимация

Цельный PNG — только anchor/static fallback. Нельзя имитировать работу стенда покачиванием всей картинки.

Причинный цикл:

`OFF → IDLE → NOTICE → WORK → FINISH → COOLDOWN → IDLE`

`WORK`:

1. `clamp_left` и `clamp_right` закрываются на двигателе;
2. `mount` принимает нагрузку;
3. происходит burn;
4. приборный узел реагирует на реальные тестовые данные;
5. двигатель выключается;
6. зажимы открываются.

Пламя, heat haze, свет, частицы и показания приборов принадлежат коду. Вибрация допустима для двигателя/mount, но не для всего стенда целиком.

Отдельные cut-out parts и измеренные pivots будут добавлены отдельным rig-pass. До этого активная WORK-анимация в gameplay не включается.

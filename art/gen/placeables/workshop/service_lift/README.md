# W01 — Сервисный подъёмник (`service_lift`)

Нарезанный anchor-art для покупаемого объекта мастерской. Источник — утверждённый 3×2 atlas imagegen; стиль определяется `art/style_bible.txt`, роль и gameplay contract — `art/placeables/PRODUCTION_MANIFEST.md`.

## Соответствие эпох

| файл | эпоха | год | визуальная стадия |
|---|---|---:|---|
| `e0_1978.png` | E0 | 1978 | цепная таль + сварная рама, открытая механика |
| `e1_1986.png` | E1 | 1986 | гидравлический сервисный подъёмник |
| `e2_1998.png` | E2 | 1998 | мостовая сервисная рама с моторизованной кареткой |
| `e3_2015.png` | E3 | 2015 | модульный сервисный rig |
| `e4_2035.png` | E4 | 2035 | роботизированная сервисная ячейка с сочленёнными руками |
| `e5_2060.png` | E5 | 2060 | кольцевая автономная сервисная система |

Каждый PNG имеет одинаковую ячейку `512×512`, поэтому registration между эпохами не плавает. Целевой игровой envelope объекта: `190×230 LP`.

## Alpha

Imagegen оставил слабый почти прозрачный haze в пустом фоне. При импорте:
- alpha `<=12` очищен до `0`;
- alpha `>=248` приведён к `255`;
- промежуточная alpha на реальном крае сохранена.

## Placement anchor

`manifest.json` содержит **измеренный** bottom-center фактического видимого bbox каждой эпохи в source pixels. Это допустимый placement anchor для статического anchor-art.

Он не является pivot для движущихся частей.

## Анимация

Цельный PNG используется только как anchor/reference и как статический fallback.

Нельзя имитировать работу подъёмника покачиванием/вращением/масштабированием целого изображения. По `ref2game` механика должна быть разрезана на реальные части.

Событийная схема:

`OFF → IDLE → NOTICE → WORK → FINISH → COOLDOWN → IDLE`

Главные события:
- `workshop_enter` — сервисный узел подходит/готовится к ракете;
- `loadout_changed` — реально снимает/ставит модуль;
- `launch_prepare` — инструмент отходит и паркуется.

### По эпохам

- **E0 1978:** каретка/таль едет по балке, крюк поднимается/опускается; длина цепи рисуется кодом.
- **E1 1986:** движется гидравлическая сервисная каретка и подвес; шланги дают вторичную реакцию.
- **E2 1998:** независимы мостовая каретка и сервисная головка.
- **E3 2015:** независимы модульная каретка, захват и service head.
- **E4 2035:** обязателен cut-out rig двух роботизированных рук: shoulder → elbow → wrist → gripper.
- **E5 2060:** ring статичен; отдельные manipulators работают через реальные joints. Cyan-индикация и glow принадлежат коду.

`manifest.json` намеренно не содержит выдуманных joint coordinates: они появятся только после отдельной генерации part-sheet и измерения утверждённых частей.

## Следующий ref2game шаг

1. Generate isolated part-sheet для W01 по каждой эпохе/семейству частей.
2. Import в `art/gen`.
3. Измерить реальные shoulder/elbow/wrist/carriage pivots.
4. Собрать era-atlas каждой детали.
5. Добавить rig в `live/`.
6. Render motion sheet и QA; только после этого включать активную WORK-анимацию.

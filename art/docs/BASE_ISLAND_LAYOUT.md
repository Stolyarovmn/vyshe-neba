# Стартовый остров и размещение расширений базы

Этот документ фиксирует геометрию стартового острова и канонические позиции покупок текущей системы развития базы. Машиночитаемый источник: `art/placeables/BASE_ISLAND_LAYOUT.json`.

## Стартовое состояние

В начале игры на острове присутствуют только природный рельеф, берег, пустые строительные террасы, сервисные дорожки и стартовый стол с минимальным основанием.

Ни одна покупаемая постройка не baked в фон. `beacons`, `weather`, `gantry`, `fuel`, `rescue`, `service`, `deluge`, `radar`, `logistics`, `control`, `recovery`, `energy`, `observation`, `factory` появляются только после покупки.

Вода, погода, волны, дождь, штормовое затемнение, отражения и атмосферные эффекты принадлежат коду. Остров конечный: при полёте вправо он физически выходит из кадра, после чего остаются непрерывные море, горизонт и небо. Остров не растворяется прямоугольной маской и не тайлится.

## Зоны

- **Стартовая зона (`pad`)** — стартовый стол, маяки, башня обслуживания и охлаждение.
- **Техническая зона (`apron`)** — сервис, спасатели, производство и топливо.
- **Периметр и связь (`perimeter`)** — центр управления, метеостанция, радар и энергетический узел.
- **Дальний сектор (`remote`)** — наблюдение, логистика и возврат/эвакуация.

## Каноническое размещение покупок

| Покупка | Зона | Причина позиции |
| --- | --- | --- |
| Стартовые маяки | pad | по обе стороны траектории у стартового стола |
| Башня обслуживания | pad | рядом со столом, вне струи двигателя |
| Охлаждение площадки | pad | по краю стартовой площадки у коммуникаций |
| Сервисная команда | apron | первый технический карман на дороге от старта |
| Спасательная станция | apron | прямой выезд к стартовой площадке |
| Производственный цех | apron | самая крупная центральная строительная терраса |
| Топливный комплекс | apron | отдельная нижняя центральная площадка, дальше от командной зоны |
| Центр управления | perimeter | возвышенная площадка с обзором старта |
| Метеостанция | perimeter | открытая верхняя точка без экранирования |
| Радар слежения | perimeter | отдельная высокая площадка с чистым сектором обзора |
| Энергетический узел | perimeter | между технической и дальней зонами, рядом с усиливаемыми объектами |
| Наблюдательный комплекс | remote | дальний возвышенный край с видом на старт |
| Логистический терминал | remote | большая правая площадка у берега и сервисной дороги |
| Система возврата | remote | крайний правый сектор с местом для крана/эвакуатора |

Координаты хранятся одновременно как UV по острову, candidate-pixel anchor и world anchor. Это позволяет заменять художественный island asset без повторного угадывания планировки.

## Проверка полностью развитой базы

QA должен уметь включить состояние `all_base_expansions` и проверить:

1. все 14 покупок имеют anchor;
2. footprint не выходит за сушу;
3. крупные объекты не перекрываются;
4. стартовый стол и траектория запуска остаются свободными;
5. сервисная дорога остаётся визуально читаемой;
6. остров остаётся конечным объектом на фоне непрерывного моря;
7. ни одна покупка не присутствует до покупки.

## Portrait

Телефон в вертикальной ориентации использует отдельную компоновку UI. Это не поворот landscape-кадра и не неравномерное растяжение canvas. Игровая камера сохраняет мировую геометрию, а HUD/touch controls перестраиваются под портретный viewport с безопасными зонами сверху и снизу.

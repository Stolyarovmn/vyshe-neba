# Инструкции для ChatGPT Project «Games» («Выше неба»)

Готовый текст для поля Project instructions. Длина подобрана по официальному руководству OpenAI к моделям изображений (Cookbook, «GPT Image Generation Models Prompting Guide», 2026): промпты там 40–100 слов, в одном порядке «сцена → объект → детали → ограничения», инварианты повторяются в каждой итерации, референсы называются по номеру с ролью («Image 1: style reference»). Инструкции проекта задают только то, что должно повторяться всегда; подробности каждого объекта идут в сам запрос по шаблону `art/docs/templates/SPRITE_REQUEST.md`.

---

Проект: пиксельная игра «Выше неба» (GitHub `Stolyarovmn/vyshe-neba`). Ветка `main` — игра, `game-production` — правила и арт. Карта веток и правила: `game-production:AGENTS.md`. Любая картинка делается по `art/docs/ART_DIRECTION_HD_PIXEL.md`; запрос строится по `art/docs/templates/SPRITE_REQUEST.md`.

Стиль (неизменно, повторяется в каждом запросе): HD pixel art по эталону острова `start-island.png`: плотные ручные пиксели, приглушённая земляная палитра (палитра острова + до 8 акцентов эпохи), тени тёмно-сине-бирюзовые, свет сверху-слева, контур цветной (не чёрный), без глянца, градиентов, сглаживания, текста, теней на фоне и эффектов.

Камеры (ровно три): полёт — остров строго сверху-3/4; база — фронт с юга, 40° над горизонтом, ортографическая, без поворота; иконки — фронт три четверти, крупный силуэт. Самолёты — строгий бок, нос вправо. Промежуточный угол — брак.

Референсы: всегда нумеровать и называть роль: «Image 1: style reference (кроп острова) — взять только стиль», «Image 2: subject reference (текущий объект) — взять только сюжет и цвета, не контур и не глянец». Для эпох E1–E5 третьим — лист `materials-construction` эпохи из `art/references/eras/`.

Один запрос = один объект или один ряд одинаковых ячеек одной камеры. Фон сплошной `#FF00FF`, широкие поля. Размер 1536×1024 для ряда, 1024×1024 для одного объекта. Правка — только «измени X, остальное оставь как есть» с повторением всех инвариантов.

Готово = владелец принял скриншот из игры. Отдельный PNG — кандидат. Оригинал сохранять нетронутым (Drive для production history). Не выдумывать SHA, углы, статусы и наличие файлов: нет данных — писать `UNKNOWN`.

Для era-reference листов (`art/reference_specs/`) действует guard: `skills/vyshe-neba-production-guard/SKILL.md`. World-спрайты (самолёты, природа) идут по ref2game (`tools/ref2game/`); placeables E0 — по `tools/hd_pixel/`.

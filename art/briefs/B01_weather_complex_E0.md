# Паспорт E0: Метеостанция

**Объект:** `weather` · E0 / 1978. Показывает прогноз погоды в меню и на HUD, награждает за полёт сквозь шторм.

**Источник:** [buildings.js](https://github.com/Stolyarovmn/vyshe-neba/blob/da026dc9fddbb49b7804b4cfbc9b61dec2541dd0/game/src/data/buildings.js), [манифест](https://github.com/Stolyarovmn/vyshe-neba/blob/da026dc9fddbb49b7804b4cfbc9b61dec2541dd0/game/src/render/manifest.js), main `da026dc9`; сверено 2026-11-11. Наличие файла не означает приёмку владельцем.

| Эффект | Уровни 1 / 2 / 3 / 4 / 5 / 6 |
| --- | --- |
| `forecast` — Точность прогноза, % | 20 / 40 / 60 / 75 / 90 / 100 |
| `stormBonus` — Бонус за шторм, % | 10 / 20 / 30 / 40 / 50 / 60 |

Числа — номинал из кода; питание влияет на действующие эффекты.

**Части:** Опора, мачта, чашечный датчик, флюгер, аналоговый прибор. Pivot измерять на точном утверждённом арте; неизвестный — `null` с причиной.

**Состояния:** по [ASSET_STATE_SPEC](../docs/ASSET_STATE_SPEC.md) §6: `PRESS` — один показ существующего ON-клипа, если он есть; отдельный клип нажатия не рисовать. `ON` — по событию; `BLOCKED` — причина из `reasonFull` только на карточке «База»; `DENIED` — отклик карточки `kit.denyFx` ≤0,4 с, без изменения спрайта. В iso/: лампа и при необходимости дым кодом, отдельный клип не делать. Свет, вода, дым, тени и звук — код; целый PNG не качать.

**Текущие пути в main**, относительно `game/assets/eras/e0-1978/`:

- Полёт: `base/weather-complex.png` (исключение имени: `base/weather.png` отсутствует).
- База: `iso/weather.png` отсутствует в main; иконка `icons/weather.png` отсутствует в main.
- ON в `E0_BUILDING_CLIPS` отсутствует; новые кадры для base/ не делать.

**Правила и принятые решения:** HD-пиксель по острову; полёт сверху, база — изометрия 40°. Выбираемые погодные окна остаются идеей; в игре прогноз и штормовой бонус. Прежние замеры кромок — история, не блокировка нового арта.

**Приёмка:** «скриншот из игры принят владельцем»; проверить читаемость, состояния, подходы и соседей в игровом масштабе. В этом проходе приёмка не проводилась.

# Паспорт E0: Энергетический узел

**Объект:** `energy` · E0 / 1978. Мощность для всех построек. При дефиците эффекты построек пропорционально слабеют.

**Источник:** [buildings.js](https://github.com/Stolyarovmn/vyshe-neba/blob/da026dc9fddbb49b7804b4cfbc9b61dec2541dd0/game/src/data/buildings.js), [манифест](https://github.com/Stolyarovmn/vyshe-neba/blob/da026dc9fddbb49b7804b4cfbc9b61dec2541dd0/game/src/render/manifest.js), main `da026dc9`; сверено 2026-11-11. Числа — номинал из кода; питание влияет на действующие эффекты.

**Части:** Общая рама, соосные двигатель и генератор, радиатор, кожух муфты, панель, кабельный вывод. Pivot измерять на точном утверждённом арте; неизвестный — `null` с причиной.

**Состояния:** по [ASSET_STATE_SPEC](../docs/ASSET_STATE_SPEC.md) §6: `PRESS` — один показ существующего ON-клипа, если он есть; отдельный клип нажатия не рисовать. `ON` — по событию; `BLOCKED` — причина из `reasonFull` только на карточке «База»; `DENIED` — отклик карточки `kit.denyFx` ≤0,4 с, без изменения спрайта. В iso/: лампа и при необходимости дым кодом, отдельный клип не делать. Свет, вода, дым, тени и звук — код; целый PNG не качать.

**Текущие пути в main**, относительно `game/assets/eras/e0-1978/`:

- Полёт: `base/energy.png`.
- База: `iso/energy.png` отсутствует в main; иконка `icons/energy.png` отсутствует в main.
- Существующий ON: `base/anim/energy_on1.png` … `energy_on3.png`, 4 кадров с опорным, 8 кадр/с. Новые кадры для base/ не делать.
- Отдельные детали в `base/`: `feeder-pole.png`.

**Правила и принятые решения:** HD-пиксель по острову; полёт сверху, база — изометрия 40°. Узел доступен с E0; пересечения проезда подземные до подтверждения воздушного габарита. Прежние замеры кромок — история, не блокировка нового арта.

**Приёмка:** «скриншот из игры принят владельцем»; проверить читаемость, состояния, подходы и соседей в игровом масштабе. В этом проходе приёмка не проводилась.

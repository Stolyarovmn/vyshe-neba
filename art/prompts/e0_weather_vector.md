# Масштаб измерительных станций E0

Статус: проектная шкала для локальной пробы; отдельная итоговая приёмка, размещение в редакторе и публикация ещё открыты. Геометрия игровых PNG не меняется. Утверждённый 6-метровый центр управления занимает 44 px; используем 44/6 px на метр для сравнения соседних объектов. Метрические габариты здесь — проектные ограничения игры, а не размеры доказанного исторического изделия.

Метеостанция нужна по действующему `weather` для прогноза и stormBonus. Её конструкция — местная ручная измерительная мачта, флюгер, чашечный датчик, аналоговый приборный ящик. Принятое проектное основание около 0,9×0,6 м; ящик около 0,4 м шириной обеспечивает доступ к прибору человеку. По отношениям на текущем PNG это даёт мачту примерно 3,5–4 м, чашки около 0,16 м, флюгер около 0,8 м. Нельзя увеличивать всю станцию до масштаба здания ради крупной шкалы. При 44/6 px/м ширина основания около 6,6 px, полный видимый спрайт около 9×11 px. Это компактная игровая станция, не метеорологическая вышка стандартизованной высоты.

Радар нужен по действующему `radar` для заблаговременного обнаружения. Текущий E0 PNG имеет основание примерно 234 px в спрайте шириной 644 px. Проектная ширина основания 1,4 м даёт полный размах антенны около 3,85 м; ручная рукоять и азимутальная передача остаются соразмерны обслуживающему человеку. Антенные поперечные стержни — детали в плоскости решётки, их экранную длину нельзя считать высотой мачты. Ориентир полного спрайта — 28×17 px, след основания около 11×9 px. Исходник не растягивается по разным осям: рендер сохраняет пропорции PNG.

Первоначальные привязки main weather (1000,350) и radar (798,174) попадают на скалы/растительность. Это видно в `E0_EAST_terrain_grid_TEST_ONLY.png`. Для локальной пробы выбраны открытый грунт weather (1060,280), radar (830,265). Для будущего цеха оставлен участок вокруг (920,255), ширина 65 px, между радаром и станцией; отклонённый исходник цеха может использоваться только в явно помеченной контрольной композиции размеров, не как принятый игровой ресурс. Перед публикацией проверить контакт с грунтом, подход к прибору и рукояти, независимость от соседних покупок. На удалённой общей карте мелкие приборы закономерно не показывают читаемые шкалы; не увеличивать их как вывески. Приёмка source/rig/provenance актуальных main-версий не выводится из одной корректировки размера.

Только E0 получает эти переопределения. Размеры поздних уровней требуют своей эпохальной проверки и здесь не исправляются автоматически.

# Архив референсов «Выше неба»

В Google Drive хранятся только принятые листы. Порядок для каждого листа:

1. Сохранить нетронутый PNG локально. Запустить verify-source и записать SHA-256, размер и размеры изображения.
2. Выполнить визуальную проверку всех ячеек и общих критериев. Любой FAIL или PENDING оставляет PNG и протокол локально. Отклонённые попытки в Drive не загружать, включая папки _rejected.
3. После технического и визуального PASS загрузить принятый PNG, записать ID и ссылку, сверить метаданные и выполнить validate-review --image. До этого шага итоговый статус архивации остаётся незавершённым.
4. Если принята новая версия того же листа, сначала проверить её архивную запись и ссылки из репозитория. Устаревшую версию убрать из активной папки только после сверки ссылок.

При очистке ранее загруженных попыток сверять ID с протоколами и утверждённым реестром. Использовать обратимую корзину. Утверждённые оригиналы и файлы с неопределённым статусом сохранять.

## E2 → E3 technological changes

| Axis | Preserved E2 function | Replaced physical evidence in E3 |
| --- | --- | --- |
| Manufacturing | Serviceable CNC assemblies | Replaceable precision modules, modular prefabrication |
| Materials | Steel/aluminium and industrial polymer | Composite panel coupons, aluminium profiles and engineered polymers |
| Drives | Motor/servo actuation and mechanical output | Sealed precision drive cartridges with smaller external gear trains |
| Operator UI | Safety controls and electronic diagnostics | Thin LCD/OLED hardware; flatter sealed tactile controls; no deep CRT |
| Lighting | Real maintenance and status lights | Neutral/cool white LED optics, compact isolated LED status hardware |
| Utilities | Causal cable/fluid routing | Protected internal chains, blind-mate and dry-break couplings |
| Service/autonomy | Operator-guided maintenance | Digitally supervised modules with protected service interfaces |
| Architecture | Structural safety and service access | Flush-panel joints, modular seams; **not** E4 glass curtain walls |

Preserve mechanical load paths, real output shafts, replaceable service interfaces, readable mounting and safety meanings. E3 should be visibly quieter and more unified than cable-heavy E2. Do not import E4 autonomous robotics or E5 spatial holograms, hover or decorative functional light strips.

## Exclusivity rules

MC = passive material/construction only; MI = actuation/utility hardware, not complete products; CD = control/display hardware without independent warning emitters; LS = independent lamp/indicator optics, not controls. **MC18** is a passive louver whereas **MI23** is a functional replaceable filter receiver. **MC21** is a passive raceway lid whereas **MI19** is a moving enclosed cable carrier. **CD01** is an unlit physical button whereas **LS14** is only a light insert for a button. **CD16** is a display-integrated backlight layer whereas **LS06** is an independent service LED cartridge. Never combine these into unlisted products.

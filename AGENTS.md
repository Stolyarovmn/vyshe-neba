# Правила для агентов — «Выше неба»

Короткий документ. Если он противоречит более старому тексту в `art/docs/`, прав этот документ; если противоречит решению владельца в чате — право решение владельца, и его надо записать сюда или в профильный документ тем же PR.

## 1. Ветки и где что лежит

| Ветка | Роль | Что внутри |
| --- | --- | --- |
| `main` (default) | игра | `game/src` (код), `game/assets` (только активные runtime-ассеты по каноническим путям), `game/test` (юнит-тесты, `npm test`), `game/tools` (сборка, баланс-бот), `game/docs` (дизайн, архитектура, язык интерфейса, планка качества, обзор баланса). CI: сборка + тесты |
| `game-production` | производство арта и правила | `art/` (брифы, промпты, provenance, QA, approved-арт), `tools/art_pipeline`, `tools/hd_pixel`, `skills/`, `AGENTS.md`, `README.md`, `archive/` |
| `slice/e0-hd-pixel` | кандидат: вся E0 в HD-пикселе и изометрический хаб (ноябрь 2026) | до приёмки владельцем не сливать |
| `art/e0-rework2-20261109` | архив Blender/Godot пилота (`trial3d/`, ≈128 МБ бинарников, локально) | не развивать |

Не существует: `game-build`, `live/`, `outputs/rocket`, `work/`. Если документ на них ссылается, документ устарел. `clean-src`, `2d_ui-fit-fixes`, `archive` — исторические ветки.

**Перед работой закрепить SHA** `main` и `game-production` и сверять runtime только с `main:game/src/render/manifest.js` на этом SHA.

## 3. Правила, которые не обсуждаются

1. **Решения владельца о стиле, камере и балансе — закон.** Текущие: HD-пиксель по эталону острова; полёт — остров сверху, база — изометрия 40°; остаёмся на JS/canvas; мелкие баги не чинить, пока владелец недоволен картиной в целом.
2. **Готово = владелец увидел скриншот из игры и принял.** Отдельный PNG, рендер или отчёт — не приёмка. Нельзя называть тесты/CI пройденными без проверяемого результата, нельзя подставлять выдуманные файлы, SHA, углы (47° никогда не подтверждался).
3. **Ничего в `main` напрямую.** Только ветка и PR; production-файлы (`art/`, `tools/art_pipeline`) в `main` не попадают; в `main` нет копий старых картинок (`*_old`, `backup`), откат — через историю Git.
4. **Один запрос генерации = один объект или один ряд одной камеры.** Текста, теней, эффектов на спрайте нет; свет сверху-слева; фон `#FF00FF`; оригинал не трогать до архивации.
5. **Код управляет движением, светом, FX; арт даёт физические части.** Анимация — только по игровому событию, из отдельных частей, не покачиванием целого PNG. Декорации без функции не делаются.
6. **Эпохи различаются инженерией, не перекраской.** `E(n)→E(n+1)` меняет минимум 3 из 8 осей матрицы и сохраняет 2 узнаваемых признака семейства.
7. **Делегировать рутину** (массовую обработку, проверки, миграции тестов) исполнителям-агентам с точным заданием и проверкой результата; решения об облике и балансе остаются за владельцем и ведущим.
8. **Фиксировать статус словами** `изменено / не изменено`, ветка, коммит/PR, что реально запущено, что не проверено.

## 4. Guard для era-reference листов

Для листов под `art/reference_specs/*.json` действует `tools/art_pipeline/production_guard.py`: `validate-spec → build-request → verify-source → init-review → validate-review`, оригинал на Drive, точный SHA, structured review без `pending/fail`. Это единственный класс картинок, где процесс машинный; игровые спрайты E0 идут по §2 «Любая картинка в игре» и принимаются владельцем по скриншоту.

## 5. Устарело (не применять)

Генерация зданий хаба под 73° («начинка вместо крыши»), параметрические векторные исходники, Blender-спрайты `trial3d`, «E2 поэлементный режим» (`ERA_SPECIMEN_COMPOSITION.md`, удалён PR #95/#96), command-branch workflow для B01/rocket-modular (удалены), старый мир `outputs/rocket`. Подробности и причины — `art/docs/ART_DIRECTION_HD_PIXEL.md` §5 и `archive/README.md`.

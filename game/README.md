# Выше неба — новая редакция

Пиксельная аркада про многоразовую ракету: взлёт, посадка на оставшемся топливе, развитие космодрома и ракеты как единой системы, маршрут Земля → Луна → Марс. Работает на телефоне (портрет и ландшафт) и на ПК, без установки и интернета.

Идея и правила — [docs/DESIGN.md](docs/DESIGN.md), контракты модулей и фактические отличия — [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md). Старая версия остаётся в `outputs/rocket`.

## Запуск

Нужен Node.js 22 или новее.

```sh
npm install        # esbuild и playwright (нужны только для сборки и проверок)
npm run game:build # game/dist/vyshe-neba.html — один автономный файл
```

Откройте `game/dist/vyshe-neba.html` в браузере. Для разработки без сборки: `npm run game:dev` и страница `http://127.0.0.1:8800/game/index.html`.

## Управление

| Действие | Клавиатура | Касание | Геймпад |
| --- | --- | --- | --- |
| Тяга | W / ↑ (удержание) | правый рычаг | правый триггер / A |
| Наклон | A / D, ← / → | левый диск | левый стик |
| Стабилизация | Q / E | двойной тап по диску | LB |
| Форсаж | Space | кнопка молнии | RB |
| Парашют / канистра / ремонт | X / F / R | кнопки | X / Y / B |
| Пауза | P / Esc | кнопка паузы | Start |

Режим «Аркада» (тяга 0/100%) включён по умолчанию, плавная тяга «Пилот» — в настройках.

## Устройство

- `src/sim` — детерминированная симуляция полёта (без DOM, тестируется в Node).
- `src/data`, `src/rules`, `src/state` — данные прогрессии, правила покупок и зависимостей, сохранение.
- `src/audio` — процедурный звук и музыка на Web Audio (без файлов).
- `src/render` — мир: остров-хаб, полёт, частицы. Арт берётся из утверждённых каталогов репозитория.
- `src/ui`, `src/input` — интерфейс на canvas, касания, клавиатура, геймпад.
- `tools/build.mjs` — сборка в один HTML; `tools/economy-bot.mjs` — проверка баланса кампании.

## Проверки

```sh
npm run game:test
```

Запускает юнит-тесты (симуляция, данные, правила, звук, интерфейс), сборку, браузерные проверки в портрете и двух ландшафтах (390×844, 1280×720, 844×390), оффлайн-проверку звука без клиппинга и бот баланса (кампания 10–14 ч). Скриншоты складываются в `work/`.

# E1 / 1986 «Своя мастерская» — план производства (2026-11-13)

E0 принята владельцем 2026-11-13 и лежит в `main` (PR #152). E1 делается по тому же рецепту и той же планке: HD-пиксель по эталону острова, база — изометрия 40° на рельефе Blender, полёт — остров сверху, приёмка — владелец по скриншоту из игры. Язык эпохи — `game-production:art/docs/ERA_DESIGN_MATRIX.md` §4: **самоделка → промышленный стандарт** (окрашенная сталь, шкафы, гидравлика, кабельные лотки, safety-цвета, больше индикаторов, monochrome/ранний color CRT).

Ветка: `era/e1-hd-pixel` от `main` 24eb846 (worktree `vn-e1`). До приёмки владельцем в `main` не сливать.

## Что есть сейчас (снято с игры на `main`)

- База E1 рисуется прежним хабом сверху: у E1 только 8 построек `base/` старого стиля, изометрии нет.
- Ракета E1 — старые спрайты `rocket/booster|core|capsule.png`, нет цельного стека `stack_*`, опор и сопла кабины.
- В полёте кольца — «спасательные круги» старого стиля, монеты и подборы старые.
- HUD E1 (вид `led`: семисегментные цифры, светодиодные шкалы) и бумага отчёта (термолента) уже есть кодом — проверить по скриншоту, довести до планки E0.

## Правила (из приёмки E0)

- Один запрос генерации = один ряд одной камеры, фон `#FF00FF`, без текста и теней; журнал попыток — `game-production:art/review/<ключ>/LOG.md`.
- Не принимать лист, если камера не совпадает с соседями (урок входов E0: первая попытка была ~25–30° вместо 40°).
- Каждый уровень модуля должен быть виден в полёте или в ангаре (урок опор E0).
- Баланс E1 не трогать без замера (`game/tools/probe-levels.mjs`, `economy-bot.mjs --real`); потолок E1 после прохода 2 — ~74 км.

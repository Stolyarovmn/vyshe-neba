## 4. Чек-лист браузерных проверок из PITFALLS (для `npm run test:browser`, когда появится Playwright)

- Захват пальца освобождается на `pointerup`, `pointercancel`, `lostpointercapture`, переходе в меню, потере фокуса и изменении размера; проверять настоящими touch-событиями.
- При повороте canvas обратное преобразование координат: наклон и попадание в кнопки в портрете и ландшафте.
- Доступность расходников в интерфейсе совпадает с условиями физики (плотность атмосферы для парашюта).
- Обе версии справки: клавиатурная и сенсорная.
- После итогов/паузы/справки нет активных полётных подсказок.
- Fullscreen по `document.fullscreenElement` после настоящего клика; запрет выделения текста.
- Предметы не возрождаются при возврате в ячейку; пять запусков с бесконечными монетами не завершают прогрессию.

# Выше неба

Пиксельная аркада про ракету: взлетай, собирай монеты, развивай технику и базу, оставляй топливо для мягкой посадки. Путь ведёт с Земли на Луну, затем на Марс.

## Играть

Нужен Node.js 22 или новее. Склонируй репозиторий и собери автономный файл: `npm run build` создаст `outputs/Выше неба.html` (установка пакетов не требуется). Открой его в современном браузере. Файл автономный: интернет для игры не нужен. Готовую сборку каждого прогона CI можно скачать из артефактов GitHub Actions. Сохранение хранится в браузере, его можно экспортировать и импортировать в настройках.

На телефоне открытие локального HTML зависит от браузера и файлового менеджера. Для запуска по сети можно разместить содержимое outputs/rocket/dist на любом статическом хостинге.

## Новая редакция

В папке [game](game/README.md) развивается новая редакция игры: портретный и горизонтальный режимы, процедурный звук, игровой интерфейс на canvas и связанное развитие ракеты и базы (Земля → Луна → Марс). Сборка: `npm run game:build`, проверки: `npm run game:test`. Классическая версия ниже остаётся рабочей.

## Управление

| Действие | ПК | Телефон |
| --- | --- | --- |
| Тяга | Удерживать W / ↑ | Удерживать палец на игровом поле |
| Наклон | A/D / ←/→ | Вести палец влево / вправо |
| Выравнивание | S / ↓ | Переместить палец к исходной позиции |
| Форсаж | W + Space | Удерживать молнию вторым пальцем |
| Парашют | X | Кнопка парашюта |
| Канистра / ремонт | F / R | Соответствующие кнопки |
| Пауза | P / Esc | Кнопка паузы |

Посадка выполняется обычной тягой: сначала погаси скорость, затем подгазовывай. Манёвровые сопла также расходуют топливо. В настройках доступен классический профиль с автотягой: S выключает двигатель, W включает форсаж.

## Исходники

- outputs/rocket/dist — игра, изображения и модули Canvas/JavaScript.
- outputs/rocket/build.cjs — сборка автономного HTML без сторонних пакетов.
- outputs/rocket/qa-*.cjs и qa.cjs — проверки физики, интерфейса, звука и управления.
- outputs/rocket/study — разбор механик, решения и известные регрессии.
- [Подробная инструкция](outputs/rocket/Прочти%20меня.md).

## Сборка и проверки

Нужен Node.js 22 или новее. Для сборки достаточно:

```sh
npm run build
```

Для полного набора проверок установи зависимости и Google Chrome:

```sh
npm install
npm test
```

Тесты используют Playwright и установленный Chrome (канал chrome). Промежуточные снимки сохраняются в work и не попадают в Git.

# Выше неба

Пиксельная аркада про многоразовую ракету и космодром на острове: короткие вылеты (1–3 минуты), мягкая посадка на остатке топлива, развитие базы и ракеты через шесть эпох (1978–2060), маршрут Земля → Луна → Марс. Браузер и телефон, без установки: вся игра собирается в один HTML.

Эта ветка (`main`) — игра целиком: код, активные ассеты, тесты, сборка, документы дизайна. Производство арта и правила для агентов — ветка `game-production` (`AGENTS.md`, `art/docs/ART_DIRECTION_HD_PIXEL.md`).

## Запуск

```bash
npm install
npm run dev        # http://127.0.0.1:8800/game/  (ES-модули без сборки)
npm run build      # game/dist/vyshe-neba.html — автономный файл
npm test           # юнит-тесты симуляции, данных, правил, рендера, интерфейса (node:test)
npm run balance    # баланс-бот на настоящей симуляции: минуты на эпоху, вердикт по допускам
```

Нужен Node ≥ 22. Браузерные проверки (`npm run test:browser`) требуют отдельно установленный Playwright и в CI не идут.

## Структура

```
game/
  index.html        dev-вход
  src/
    main.js         цикл, состояния, переходы
    data/           эпохи, тела, модули, постройки, контракты, достижения, экономика (чистые данные)
    rules/          чистые функции над профилем: покупки, требования, эффекты, награды, итоги полёта
    state/          профиль, сохранение, миграции
    sim/            детерминированная симуляция полёта (без DOM и Math.random)
    render/         ассеты, камера, сцены (хаб, полёт), частицы
    ui/             canvas-интерфейс: экраны, HUD, пиксельный шрифт, скины эпох
    audio/          процедурный звук и музыка
    input/          клавиатура, касания, геймпад
  assets/           только активные runtime-ассеты по каноническим путям (eras/e<N>-<год>/…, shared/…)
  test/             *.test.mjs (node:test) и *.browser.cjs (Playwright)
  tools/            build.mjs, economy-bot.mjs (+ adapter), probe-*.mjs, подготовка ассетов (*.py)
  docs/             DESIGN.md, ARCHITECTURE.md, UI_LANGUAGE.md, QUALITY_BAR.md, BALANCE_REVIEW_20261110.md, reference/
```

## Документы

| Документ | Зачем |
| --- | --- |
| `game/docs/DESIGN.md` | что это за игра: столпы, структура, прогрессия, экономика, интерфейс, звук |
| `game/docs/ARCHITECTURE.md` | контракт между модулями, профиль, симуляция, рендер |
| `game/docs/UI_LANGUAGE.md` | язык интерфейса: игра, а не сайт; пиксельный шрифт, рамки, приборы, эпохи |
| `game/docs/QUALITY_BAR.md` | планка качества: чек-листы кадра, ощущения, читаемости, производительности, приёмки |
| `game/docs/BALANCE_REVIEW_20261110.md` | обзор баланса на реальной симуляции и предложения по числам |
| `game/docs/TEST_MIGRATION_20261110.md` | как тесты вернулись в `main`, что переписано, что не покрыто |
| `game/docs/reference/` | справочники, которые читают тесты (трафик по высотам и эпохам, аэростаты) |

## Правила ветки

- Прямых пушей в `main` нет: ветка → PR → CI (`.github/workflows/game-ci.yml`: чистота дерева, манифест, сборка, контрольная сумма, `npm test`).
- Картинки в `game/assets` заменяются по месту; копий `*_old`, `backup` не бывает, откат — через историю Git.
- Размеры и якоря спрайтов задаёт `game/src/render/manifest.js`; он же источник истины для раскладки острова.
- Любая новая картинка делается по `game-production:art/docs/ART_DIRECTION_HD_PIXEL.md` и принимается владельцем по скриншоту из игры.
